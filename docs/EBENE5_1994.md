# Verbandsligen Ebene 5 1994 bis ~2001 (25.10.2026)

Sheet-Punkt „Verbandsliga Südwest hat Lücken … Prüfe mal, wie weit die Ligen zurück gingen“. Befund: fast alle obersten
Verbandsligen fehlten 1994 bis ~2001 – die Naht zwischen f-archiv (Ebene 4 bis 1993/94) und fussball.de (ab 2001). Damals
Ebene 5, nie übernommen. Quelle: der f-archiv-Export des Nutzers (`~/Downloads/farchiv_output/alle_tabellen_final.csv`).

## Umfang

18 Ligen, 162 Liga-Saisons, 2.757 Zeilen (`tools/farchiv_ebenen.mjs` `REGELN_E5`, Nachfolger in `historie_einbau.mjs`
`LIGA_NACHFOLGER`, je Liga bis ein Jahr vor dem ersten fussball.de-Jahr der heutigen Liga). Nicht dabei: Hessen, Bayern,
Westfalen (heute mehrere Nachfolger). `history_ext.js` +62 KB.

Verbandsliga Niederrhein 1999/2000 (damals unter der Oberliga **Nordrhein**; „Oberliga Niederrhein“ ist nur der heutige Name im
Spiel) fehlt bei f-archiv und kommt aus Wikipedia (`tools/wiki_tabellen.mjs`, Hinweis des Nutzers).

Restlücken geschlossen (26.10.2026) – direkt unter der heutigen Spiel-ID, wie die Niederrheinliga 2008–11 (gleiche Liga, `fe:1` wo
damals andere Ebene), keine eigenen Liga-IDs:
- Verbandsliga Saar 2006/07–2008/09 → `6-3` aus fussball.de (`fbde_ebene58.mjs`; 2006–07 Ebene 5 = `fe`, 2008 schon Ebene 6).
  Wikipedia hat keine Saisonartikel. Der Filter „Verbandsliga Saar“ gilt sonst weiter: ab 2009 heißt so die Ebene-7-Liga.
- Mittelrheinliga 2008/09–2011/12 → `5-12` aus fussball.de (damals Ebene 6 unter der NRW-Liga, `fe`); ab 2012 Wikipedia.
- Verbandsliga Mecklenburg-Vorpommern 2008/09 → `6-19` aus Wikipedia (`wiki_ebene45.mjs`); fussball.de hat sie erst ab 2009/10.
Die neue Wikipedia-Tabelle verschob FSV Malchin auf eine neue ID – Anker `hist_wk_fsv1919malchin`. Achtung beim Nachziehen:
`hist_anker_nachziehen.cjs` holte auch eine GEWOLLTE Verschiebung zurück (Darmstadt 98 II, neu im Spiel, alte Zeilen an der
Spiel-ID) – vorgeschlagene Anker immer gegen den Vergleich lesen. Prüfung `.claude/skills/run/restluecken_check.mjs`.

Liga darüber (Navigation, Ligaverlauf): aus den Vereinswechseln wie Ebene 4 vor 1994 (`ableiten(..., 4, ...)` in Abschnitt 6c2),
355 Wechsel bestätigen, 0 widersprechen.

## S/U/N nach 3-Punkte-Regel geschätzt

Ab 1995/96 nennt f-archiv für diese Ligen nur Spiele, Tore und Punkte. Das alte Schätzmodell (4a in `historie_dryrun.mjs`)
brauchte Plus- UND Minuspunkte (2-Punkte-Regel) und liess 1.585 Zeilen bei 0-0-0 – die Ewige Tabelle zählte sie als 0 Spiele.
Neu `schaetze3`: 3S+U = P, S+U+N = Sp, frei ist die Remiszahl, Modell über die 2-Punkte-Stärke P−S (dreimal angenähert).
Gegenprobe an 3.666 echten Zeilen ab 1995: MAE 0,61 Siege, 99,9 % höchstens 2 daneben; Selbsttest Remisquote 0: MAE 2,22.

**Falle, die das verdeckt hat:** `historie_neuaufbau_vergleich.cjs` suchte 0-0-0 nur in GEÄNDERTEN Zeilen, nicht in neuen
Tabellen. Behoben; der gesicherte kaputte Stand fällt jetzt mit 1.585 Zeilen durch.

## ID-Anker (`tools/hist_id_anker.json`)

Die neuen Daten verschoben über den Namensabgleich der Vorstufen 422 bestehende Zeilen (80 Vereine) – darunter Spielvereine
(VfB Merseburg, SG Meisenheim) und Saisons der 1960er (Doppelbelegung Verbandsliga Hamburg 1965/66). Der Anker legt am Eingang von
`historie_einbau.mjs` (Abschnitt 0) neue ID → alte ID zurück, bevor Aliase und Zusammenlegung greifen, und merkt sich den alten
Vereinsnamen (`_namen`, Namens-Aliase hängen daran: „VFB IMO Merseburg“).

```bash
HIST_ANKER_BASIS=1 node tools/historie_einbau.mjs        # heutigen Stand festhalten (vor der neuen Lieferung)
# ... Kette mit der neuen Lieferung ...
HIST_ANKER_ABLEITEN=1 node tools/historie_einbau.mjs     # Eingangs-IDs vergleichen -> hist_id_anker.json
node tools/hist_anker_nachziehen.cjs && node tools/historie_einbau.mjs   # wiederholen, bis nichts dazukommt
node tools/historie_neuaufbau_vergleich.cjs              # Rest: tools/_dryrun/anker_rest.txt
```

Ergebnis: 101 IDs, 15 Wechsel bleiben, beide gewollt – Wuppertaler SV Amateure 1968–79 = Wuppertaler SV II (A = II), und die
doppelte ID von Preußen Magdeburg („MSV 90 Preussen Magdeburg“ = „Magdeburger SV 90 Preussen“). Von Hand: Alias
„Güldenstern Stade“ (1965/66 = TuS), „Delmenhorster SC“. 7 geschätzte Zeilen (Landesligen Bayern/Hessen, 2. AL Südwest)
verteilen dieselben Punkte minimal anders (Modell mit mehr Daten).

Prüfpunkt: SV St. Ingbert hat schon vorher zwei IDs (`hist_fa_svstingbert`, `…2`); die neuen Saisons 1999/2000 und 2000/01
verteilen sich auf beide.
